# Digital Logic Circuit Designer & Analyzer

### An Interactive Digital Logic Design, Simulation & Analysis Tool

**Digital Logic Circuit Designer & Analyzer** is a web-based educational application for designing, simulating, and analyzing digital logic circuits through an interactive visual interface.

The application helps students, educators, and electronics enthusiasts explore digital logic concepts, construct circuits, and examine their logical behavior.

## Launch the Application

**[Open Digital Logic Circuit Designer & Analyzer](https://essamassaf.github.io/DigitalLogicAnalyzer/)**

The application runs directly in a web browser.

## Key Features

### Digital Circuit Design
- Interactive circuit design workspace.
- Seven fundamental logic gates: AND, OR, NOT, NAND, NOR, XOR, and XNOR.
- Configurable digital inputs and outputs.
- Drag-and-drop components.
- Wire connections, branches, and junction nodes.
- Component selection, movement, and rotation.

### Digital Logic Components
- Half Adder and Full Adder.
- Parallel Adder.
- Digital Comparator.
- Encoder and Decoder.
- Multiplexer (MUX) and Demultiplexer (DEMUX).
- SR, D, and JK Latches.
- Master-Slave Flip-Flops.
- Clock signal source.

### Logic Analysis
- Boolean Equations.
- Truth Table Generation.
- Karnaugh Maps (SOP and POS).
- Boolean Algebra and Simplification.
- De Morgan's Theorems.
- Distributive, Commutative, and Associative Laws.
- Minterms and Maxterms.
- Timing Diagrams.

### Project Management
- Create and open circuit projects.
- Save circuit designs.
- Undo and Redo.
- Print circuit diagrams and analysis results.
- Export reports to PDF.

## Technologies

The application is developed using:

- HTML5
- CSS3
- JavaScript

## Educational Purpose

This project provides an interactive environment for understanding digital electronics, Boolean algebra, combinational logic, and sequential logic.

It is designed to support practical learning and experimentation with digital circuits.
